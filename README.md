## Веб-сервис для сокращения URL-адресов, написанный на Go.

### Возможности

- Сокращение длинных URL-адресов
- Перенаправление по коротким ссылкам
- Удаление ссылок
- Ограничение частоты запросов (Rate Limiting)
- Логирование запросов
- Конфигурация через YAML-файл

### Технологии

- **Язык:** Go
- **База данных:** PostgreSQL (pgx)
- **HTTP-сервер:** Chi router
- **Логирование:** Slog

### Запуск

```bash
docker-compose up -d

go run cmd/app/main.go
```

### API Endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/url` | Создать короткую ссылку |
| GET | `/{alias}` | Перейти по короткой ссылке |
| DELETE | `/api/url` | Удалить ссылку |

Настройки находятся в файле `config/config.yaml`:
